Privacy Policy

Last Updated: August 11, 2026

1. Overview

This Privacy Policy describes how happy_days_auto_post ("the App") collects, uses, and protects user information when accessing TikTok's API services.

2. Information We Collect

The App collects the following information through TikTok's OAuth 2.0 authorization:

  • Basic profile information: Open ID, display name, and avatar (via user.info.basic scope)
  • Video upload permission: Authorization to upload video content to the user's TikTok account (via video.upload scope)

The App does not collect passwords, payment information, or any personal data beyond what is required for TikTok API authorization.

3. How We Use Information

The collected information is used solely for the following purposes:

  • Authenticating the user with TikTok's API
  • Uploading video content to the user's TikTok account

4. Data Storage

OAuth access tokens are stored locally on the user's own device. No user data is transmitted to or stored on external servers operated by the App developer.

5. Data Sharing

The App does not share, sell, or transfer any user data to third parties. Data is only exchanged between the user's device and TikTok's official API endpoints.

6. Data Retention

OAuth tokens are retained only as long as the user authorizes the App. Users can revoke access at any time through their TikTok account settings, which will immediately invalidate all stored tokens.

7. Children's Privacy

The App is not intended for use by individuals under the age of 13. We do not knowingly collect information from children.

8. Changes to This Policy

This Privacy Policy may be updated from time to time. Any changes will be reflected on this page with an updated revision date.
