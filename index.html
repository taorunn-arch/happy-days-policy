About

happy_days とは

日本各地の魅力・熊本の復興応援・花言葉・音楽クイズなど、多彩なテーマで毎日動画を制作・配信しています。

日本国内の観光スポット・文化・食・歴史をわかりやすく紹介するショート動画を、YouTube Shorts・TikTok・Instagram Reels などのプラットフォームに毎日投稿しています。

TikTok の Content Posting API を活用し、制作した動画を自動的に投稿・管理します。視聴者の皆さんに日本の魅力をより多く、より早くお届けすることを目指しています。
